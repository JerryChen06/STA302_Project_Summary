The analysis I’ve done so far is a little involved, so I decided to type this quarto doc to summarize it. For my research I’ve generated a LOT of analyses similar to this, so I figured I may as well apply the same tools for our initial exploratory analysis. I’ll try to explain each figure as best I can, but I apologize if it’s confusing.

The following heatmap was constructed as follows: Each row and column represents one of the predictors from the CCHS dataset (i.e. the elements of the vector above). The intersection between them represents the correlation between the two predictors (red = closer to 1, blue = closer to -1). For example, the diagonal is all 1 because the correlation between a predictor and itself is always 1. I first did this across all predictors that had more than 1 unique value, since predictors that take on only one value wouldn’t be interesting to find correlations with. I then “clustered” the values, which basically means sorting the rows and columns based on how similar they are to each other. This creates “clusters” of predictors that share similar values to each other, which will look like chunks of red and blue.

This heatmap isn’t super interpretable immediately because of the size (234x234). But there are a few things that are potentially useful.

Firstly, notice the huge red chunks. These are groups of predictors that have basically the same correlation patterns. When we zoom in and look at the members of each cluster, it makes sense because a lot of them are part of the same group. For example, daily consumption of various foods/beverages. This means two things:

  1. We can “collapse” this chunk into just a single chunk called “Daily Consumption of Foods” taking the average correlations, and replot the heatmap. The heatmap will become more interpretable without losing much data.
  2. We can look at JUST this cluster, and investigate how each predictor interacts with each other. Since we know there are underlying relationships between them, it may be interesting to see which relationships are the “true” drivers of the correlation. The best example I can think of is the correlation between daily consumption of fruit and daily consumption of energy drinks. These are highly correlated numerically, but if we were to run regression on this with other predictors, we may see that there is actually little relationship. The most likely predictors by which this would work would likely be other predictors in the cluster, such as exercise or physical activity (which is actually grouped together in the first big red cluster).

Secondly, notice how there are various correlations between each cluster. After we compress each cluster into a core “identity”, we can better interpret the correlations between variables that aren’t extremely similar. For example, we see that one of the last clusters is pretty highly correlated with the middle clusters, which corresponds to aerobic sport activity and COVID19 vaccination precautions, which seems pretty disconnected. Of course we can’t conclude that they’re actually connected, but they may be interesting predictors to consider.

Lastly, if we are interested in a specific response (e.g. Health index), we can just look at that row/column, and look at what is correlation and anticorrelated. This can help us figure out potential predictors to include in the analysis.

# Here, I'm just computing the total number of unique values each predictor takes. For example, categorical and discrete variables would only take a few unique values, whereas continuous variables would take thousands of unique values. 
unique_values <- pumf |> 
  summarize(across(everything(), n_distinct)) |> 
  t() 

colnames(unique_values) <- "num_unique_val"

# The idea here is that any predictor that takes on only 1 value is not interesting, so I just filtered them out here. 
non_variables <- rownames(data.frame(unique_values) |> filter(num_unique_val == 1))

# Heatmap: Predictor x Predictor, coloured by correlation. 
visualize_correlation_matrix <- function(df, column_ids) {
  
  # Selecting just the column_ids
  subset <- df[, column_ids] 
  

  corr_mat <- cor(subset) 
  
  rownames(corr_mat) <- dict[rownames(corr_mat)] # Matching rownames to the description for easier interpretation

  # My PI gave me this colour scheme. Blue is more negative and Red is more positive
  cols = c("#2166ac",
             "#4393c3",
             "#92c5de", 
             "#d1e5f0",
             "#f7f7f7",
             "#fddbc7",
             "#f4a582",
             "#d6604d",
             "#b2182b")
  sim_col <- circlize::colorRamp2(seq(-1, 1, length.out = length(cols)), cols)

  # This is from the ComplexHeatmap package. This section just creates the heatmap, clusters it, and saves it. 

  ht <- Heatmap(
    corr_mat,
    col = sim_col,
    show_row_dend = FALSE,
    show_column_dend = FALSE,
    show_heatmap_legend = FALSE
  )

  png(
    "predictor_corr.png", 
    width = 40,
    height = 40,
    units = "in",
    res = 250
  )
  
  draw(ht)
  
  dev.off()

  return(rownames(corr_mat)[row_order(draw(ht))])
  
}

# column_ids here is just all of the predictors (colnames) EXCEPT for the variables that only take one value (non_variables). This created the heatmap above
visualize_correlation_matrix(
    df = pumf, 
    column_ids = setdiff(colnames(pumf), non_variables)
)
